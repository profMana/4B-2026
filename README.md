# 🚀 4B info - Esercizi Web Development Avanzato (JS ES6, AJAX, PHP)

Raccolta di esercizi di **Web Development frontend avanzato e backend**. 
In questo repository sono raccolti gli esercizi di **JavaScript ES6**, **AJAX**, **PHP** e gestione dati svolti in classe.

---

## 📂 Struttura del Repository

Il progetto è organizzato in cartelle tematiche, ordinate per tecnologia e flusso di lavoro:

```text
├── 01-JS-ES6/         # Richiami di JavaScript moderno (arrow functions, classi, destrutturazione)
├── 02-XML-JSON/       # Formati di interscambio dati, parsing e strutturazione
├── 03-jQuery/         # Manipolazione semplificata del DOM e gestione eventi
├── 04-AJAX/           # Richieste asincrone (XMLHttpRequest, Fetch API, \$.ajax)
├── 05-Geolocation/    # Gestione delle API di geolocalizzazione del browser
└── 06-PHP/            # Script lato server, elaborazione dati e integrazione backend
```

---

## 🛠️ Tecnologie Utilizzate

*   **JavaScript ES6:** Sintassi moderna per un codice frontend più efficiente e pulito.
*   **XML & JSON:** Strutturazione e passaggio dei dati tra client e server.
*   **jQuery:** Libreria JavaScript per velocizzare lo sviluppo e la gestione del DOM.
*   **AJAX:** Comunicazione asincrona per aggiornare le pagine senza ricaricarle.
*   **Geolocation API:** Servizi nativi del browser per il posizionamento geografico.
*   **PHP:** Sviluppo backend lato server per la gestione delle richieste e delle risposte.

---

## 📈 Obiettivi  

*   [ ] Integrare le nuove funzionalità di JavaScript ES6 nei progetti web.
*   [ ] Saper leggere, scrivere e manipolare flussi di dati in formato XML e JSON.
*   [ ] Creare applicazioni dinamiche che comunicano in tempo reale con il server tramite AJAX.
*   [ ] Sviluppare script backend in PHP per elaborare dati ed erogare servizi al frontend.
